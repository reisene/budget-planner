# Security Policy

## Supported versions

Only the latest release (and the current `main`/`develop` code) receives
security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately using one of:

- GitHub's
  [private vulnerability reporting](https://github.com/reisene/budget-planner/security/advisories/new)
- Email: [contact@draugskoll.dev](mailto:contact@draugskoll.dev)

Please include a description, reproduction steps, affected versions, and the
potential impact.

You can expect an acknowledgement within 7 days and a status update within 30
days. We will credit reporters in the advisory unless you prefer to stay
anonymous.
